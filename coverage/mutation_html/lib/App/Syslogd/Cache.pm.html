   54:

   56: a Perl hash, forgets each one after its time to live, and keeps its total
   57: size under a limit by dropping the oldest entries first.
   58: 
   59: Its only method besides C<new()> is C<compute()>, which has the same calling
   60: convention as L<CHI>'s, so either can be given to App::Syslogd as its
   61: C<cache>.

  129: =head2 compute
  130: 
  131: Purpose: return the remembered value for a key, or compute, remember and
  132: return it.
  133: 
  134: Args:
  135: 
  136: =over 4
  137: 
  138: =item 1. The key (a string).
  139: 
  140: =item 2. How many seconds to remember a new value.  0 (or less) means
  141: "do not remember": the value is computed every time.
  142: 
  143: =item 3. A code reference that computes the value.
  144: 
  145: =back
  146: 
  147: Returns: the value (it may be C<undef>, which is remembered like any other).
  148: 
  149: Side Effects: may call the code reference; may forget the oldest entries to
  150: stay under C<max_bytes>.  A value too big to fit at all is returned but not
  151: remembered.  If the code dies, the error is passed on and nothing is
  152: remembered.
  153: 
  154: Usage:
  155: 
  156: 	my $value = $cache->compute($key, $seconds, sub { ... });
  157: 
  158: =head3 EXAMPLE
  159: 
  160: 	my $calls = 0;
  161: 	my $get = sub { $cache->compute('k', 60, sub { ++$calls }) };
  162: 	$get->();	# 1: computed
  163: 	$get->();	# 1: remembered; $calls is still 1

  186: =head3 PSEUDOCODE
  187: 
  188: 	if the key has an entry that has not expired: return its value
  189: 	value = code()
