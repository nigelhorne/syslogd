   82: =head1 DESCRIPTION
   83: 
   84: A program shows messages to people: "listening on port 514", "could not
   85: open the file", and so on.  This module keeps those messages in one place, so
   86: that they can be translated into other languages.
   87: 
   88: Each message has a I<key> (a short name, such as C<listening>) and some
   89: I<values> (such as the port number).  You give the key and the values; you
   90: get back the finished sentence in the chosen language.
   91: 
   92: Each language is a small Perl package called C<App::Syslogd::I18N::xx>
   93: (where C<xx> is the language code) with a hash called C<%Lexicon>.  The hash
   94: maps each key to its text.  The text uses the "bracket notation" of
   95: L<Locale::Maketext>:
   96: 
   97: =over 4
   98: 
   99: =item * C<[_1]>, C<[_2]>, ... are replaced by the values, in the order given
  100: by the table in L</text>.
  101: 
  102: =item * C<[quant,_1,message,messages]> chooses the singular or plural form
  103: for the number in C<[_1]>, and writes the number.
  104: 
  105: =item * C<[sprintf,%05d,_1]> formats a value, as Perl's C<sprintf> does.
  106: 
  107: =item * C<[gender,_1,his,her,their]> chooses a word by gender; see
  108: L</gender>.
  109: 
  110: =item * A real square bracket is written C<~[> or C<~]>.
  111: 
  112: =back
  113: 
  114: =head1 ENCODING
  115: 
  116: =over 4
  117: 
  118: =item * B<Language tags> must be ASCII, for example C<en> or C<en-gb>.
  119: 
  120: =item * B<Lexicon text> may contain any Unicode characters, including
  121: non-ASCII letters and emoji, if the language file starts with C<use utf8;>.
  122: The English lexicon is pure ASCII.
  123: 
  124: =item * B<Values> are copied into the message unchanged.  They may be byte
  125: strings or character strings.  Square brackets and C<~> in a value are not
  126: special: only the lexicon text is parsed.
  127: 
  128: =item * B<The result> is a Perl string.  If it contains characters above
  129: 255 (for example from a translation with emoji), set an output layer before
  130: printing it: C<binmode(STDOUT, ':encoding(UTF-8)')>.  Otherwise Perl prints
  131: a "Wide character" warning.
  132: 
  133: =back
  134: 
  135: =head1 COMMON PITFALLS
  136: 
  137: =over 4
  138: 
  139: =item * B<A translation must inherit from the English lexicon.>  If
  140: C<App::Syslogd::I18N::de> inherits only from C<App::Syslogd::I18N>, any key
  141: it does not translate makes L<Locale::Maketext> die with "maketext doesn't
  142: know how to say".  Inherit from C<App::Syslogd::I18N::en>, as in the
  143: SYNOPSIS, and missing keys fall back to English.
  144: 
  145: =item * B<Missing values become empty strings.>  C<< text('open_failed', {}) >>
  146: gives "Could not open log file : " with no warning.  This is on purpose (an
  147: error message should never fail), but check your values if a message looks
  148: incomplete.
  149: 
  150: =item * B<undef or non-numbers in a plural become 0.>
  151: C<< text('shutdown', { count => undef }) >> says "0 messages".
  152: 
  153: =item * B<An unknown key does not die.>  C<< text('no_such_key', { a => 1 }) >>
  154: returns C<no_such_key (a=1)>.  This keeps the information in an error path,
  155: but it means a misspelt key is not reported.  Test the messages you use.
  156: 
  157: =item * B<Values are matched to positions by name, not by order.>  The order
  158: of the C<[_1]>, C<[_2]> slots comes from a fixed table (see L</text>), not
  159: from the order you write the hash.  A new key must be added to that table
  160: too, or it is treated as unknown.
  161: 
  162: =item * B<gender() knows only "male" and "female".>  Any other value,
  163: including C<m>, C<f> and C<undef>, gives the neutral form.  Upper and lower
  164: case are the same.
  165: 
  166: =item * B<The language comes from the environment> when you give none:
  167: C<LANGUAGE>, C<LC_ALL>, C<LC_MESSAGES>, then C<LANG>.  A language with no
  168: lexicon falls back to English without a warning.
  169: 
  170: =item * B<Operating-system errors stay in English.>  A value such as C<"$!">
  171: is in the C locale unless the code that made it used C<use locale>, whatever
  172: C<LC_ALL> says.
  173: 
  174: =back
