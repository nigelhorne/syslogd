   89: =head1 DESCRIPTION
   90: 
   91: A program shows messages to people: "listening on port 514", "could not
   92: open the file", and so on.  This module keeps those messages in one place, so
   93: that they can be translated into other languages.
   94: 
   95: Each message has a I<key> (a short name, such as C<listening>) and some
   96: I<values> (such as the port number).  You give the key and the values; you
   97: get back the finished sentence in the chosen language.
   98: 
   99: Each language is a small Perl package called C<App::Syslogd::I18N::xx>
  100: (where C<xx> is the language code) with a hash called C<%Lexicon>.  The hash
  101: maps each key to its text.  The text uses the "bracket notation" of
  102: L<Locale::Maketext>:
  103: 
  104: =over 4
  105: 
  106: =item * C<[_1]>, C<[_2]>, ... are replaced by the values, in the order given
  107: by the table in L</text>.
  108: 
  109: =item * C<[quant,_1,message,messages]> chooses the singular or plural form
  110: for the number in C<[_1]>, and writes the number.
  111: 
  112: =item * C<[sprintf,%05d,_1]> formats a value, as Perl's C<sprintf> does.
  113: 
  114: =item * C<[gender,_1,his,her,their]> chooses a word by gender; see
  115: L</gender>.
  116: 
  117: =item * A real square bracket is written C<~[> or C<~]>.
  118: 
  119: =back
  120: 
  121: =head1 ENCODING
  122: 
  123: =over 4
  124: 
  125: =item * B<Language tags> must be ASCII, for example C<en> or C<en-gb>.
  126: 
  127: =item * B<Lexicon text> may contain any Unicode characters, including
  128: non-ASCII letters and emoji, if the language file starts with C<use utf8;>.
  129: The English lexicon is pure ASCII.
  130: 
  131: =item * B<Values> are copied into the message unchanged.  They may be byte
  132: strings or character strings.  Square brackets and C<~> in a value are not
  133: special: only the lexicon text is parsed.
  134: 
  135: =item * B<The result> is a Perl string.  If it contains characters above
  136: 255 (for example from a translation with emoji), set an output layer before
  137: printing it: C<binmode(STDOUT, ':encoding(UTF-8)')>.  Otherwise Perl prints
  138: a "Wide character" warning.
  139: 
  140: =back
  141: 
  142: =head1 COMMON PITFALLS
  143: 
  144: =over 4
  145: 
  146: =item * B<A translation must inherit from the English lexicon.>  If
  147: C<App::Syslogd::I18N::de> inherits only from C<App::Syslogd::I18N>, any key
  148: it does not translate makes L<Locale::Maketext> die with "maketext doesn't
  149: know how to say".  Inherit from C<App::Syslogd::I18N::en>, as in the
  150: SYNOPSIS, and missing keys fall back to English.
  151: 
  152: =item * B<Missing values become empty strings.>  C<< text('open_failed', {}) >>
  153: gives "Could not open log file : " with no warning.  This is on purpose (an
  154: error message should never fail), but check your values if a message looks
  155: incomplete.
  156: 
  157: =item * B<undef or non-numbers in a plural become 0.>
  158: C<< text('shutdown', { count => undef }) >> says "0 messages".
  159: 
  160: =item * B<An unknown key does not die.>  C<< text('no_such_key', { a => 1 }) >>
  161: returns C<no_such_key (a=1)>.  This keeps the information in an error path,
  162: but it means a misspelt key is not reported.  Test the messages you use.
  163: 
  164: =item * B<Values are matched to positions by name, not by order.>  The order
  165: of the C<[_1]>, C<[_2]> slots comes from a fixed table (see L</text>), not
  166: from the order you write the hash.  A new key must be added to that table
  167: too, or it is treated as unknown.
  168: 
  169: =item * B<gender() knows only "male" and "female".>  Any other value,
  170: including C<m>, C<f> and C<undef>, gives the neutral form.  Upper and lower
  171: case are the same.
  172: 
  173: =item * B<The language comes from the environment> when you give none:
  174: C<LANGUAGE>, C<LC_ALL>, C<LC_MESSAGES>, then C<LANG>.  A language with no
  175: lexicon falls back to English without a warning.
  176: 
  177: =item * B<Operating-system errors stay in English.>  A value such as C<"$!">
  178: is in the C locale unless the code that made it used C<use locale>, whatever
  179: C<LC_ALL> says.
  180: 
  181: =back

  367: =head2 gender
