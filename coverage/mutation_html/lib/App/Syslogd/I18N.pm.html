   88: =head1 DESCRIPTION
   89: 
   90: A program shows messages to people: "listening on port 514", "could not
   91: open the file", and so on.  This module keeps those messages in one place, so
   92: that they can be translated into other languages.
   93: 
   94: Each message has a I<key> (a short name, such as C<listening>) and some
   95: I<values> (such as the port number).  You give the key and the values; you
   96: get back the finished sentence in the chosen language.
   97: 
   98: Each language is a small Perl package called C<App::Syslogd::I18N::xx>
   99: (where C<xx> is the language code) with a hash called C<%Lexicon>.  The hash
  100: maps each key to its text.  The text uses the "bracket notation" of
  101: L<Locale::Maketext>:
  102: 
  103: =over 4
  104: 
  105: =item * C<[_1]>, C<[_2]>, ... are replaced by the values, in the order given
  106: by the table in L</text>.
  107: 
  108: =item * C<[quant,_1,message,messages]> chooses the singular or plural form
  109: for the number in C<[_1]>, and writes the number.
  110: 
  111: =item * C<[sprintf,%05d,_1]> formats a value, as Perl's C<sprintf> does.
  112: 
  113: =item * C<[gender,_1,his,her,their]> chooses a word by gender; see
  114: L</gender>.
  115: 
  116: =item * A real square bracket is written C<~[> or C<~]>.
  117: 
  118: =back
  119: 
  120: =head1 ENCODING
  121: 
  122: =over 4
  123: 
  124: =item * B<Language tags> must be ASCII, for example C<en> or C<en-gb>.
  125: 
  126: =item * B<Lexicon text> may contain any Unicode characters, including
  127: non-ASCII letters and emoji, if the language file starts with C<use utf8;>.
  128: The English lexicon is pure ASCII.
  129: 
  130: =item * B<Values> are copied into the message unchanged.  They may be byte
  131: strings or character strings.  Square brackets and C<~> in a value are not
  132: special: only the lexicon text is parsed.
  133: 
  134: =item * B<The result> is a Perl string.  If it contains characters above
  135: 255 (for example from a translation with emoji), set an output layer before
  136: printing it: C<binmode(STDOUT, ':encoding(UTF-8)')>.  Otherwise Perl prints
  137: a "Wide character" warning.
  138: 
  139: =back
  140: 
  141: =head1 COMMON PITFALLS
  142: 
  143: =over 4
  144: 
  145: =item * B<A translation must inherit from the English lexicon.>  If
  146: C<App::Syslogd::I18N::de> inherits only from C<App::Syslogd::I18N>, any key
  147: it does not translate makes L<Locale::Maketext> die with "maketext doesn't
  148: know how to say".  Inherit from C<App::Syslogd::I18N::en>, as in the
  149: SYNOPSIS, and missing keys fall back to English.
  150: 
  151: =item * B<Missing values become empty strings.>  C<< text('open_failed', {}) >>
  152: gives "Could not open log file : " with no warning.  This is on purpose (an
  153: error message should never fail), but check your values if a message looks
  154: incomplete.
  155: 
  156: =item * B<undef or non-numbers in a plural become 0.>
  157: C<< text('shutdown', { count => undef }) >> says "0 messages".
  158: 
  159: =item * B<An unknown key does not die.>  C<< text('no_such_key', { a => 1 }) >>
  160: returns C<no_such_key (a=1)>.  This keeps the information in an error path,
  161: but it means a misspelt key is not reported.  Test the messages you use.
  162: 
  163: =item * B<Values are matched to positions by name, not by order.>  The order
  164: of the C<[_1]>, C<[_2]> slots comes from a fixed table (see L</text>), not
  165: from the order you write the hash.  A new key must be added to that table
  166: too, or it is treated as unknown.
  167: 
  168: =item * B<gender() knows only "male" and "female".>  Any other value,
  169: including C<m>, C<f> and C<undef>, gives the neutral form.  Upper and lower
  170: case are the same.
  171: 
  172: =item * B<The language comes from the environment> when you give none:
  173: C<LANGUAGE>, C<LC_ALL>, C<LC_MESSAGES>, then C<LANG>.  A language with no
  174: lexicon falls back to English without a warning.
  175: 
  176: =item * B<Operating-system errors stay in English.>  A value such as C<"$!">
  177: is in the C locale unless the code that made it used C<use locale>, whatever
  178: C<LC_ALL> says.
  179: 
  180: =back
